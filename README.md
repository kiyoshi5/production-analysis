# 製造ラインのセンサーデータ分析

## 1. プロジェクト概要

Pythonを使用した製造ラインのセンサーデータ分析を目的とした個人制作プロジェクトです。

プラスチック成形工場の3つの製造ラインから取得される温度・圧力・振動データを想定し、データの集計、分析、可視化を行います。

※ 本プロジェクトでは、分析用のサンプルデータをPythonで生成しています。実際の製造現場のデータではありません。

## 2. 使用技術

- Python
- Jupyter Notebook
- pandas
- NumPy
- matplotlib
- seaborn

## 3. データ概要

- 対象：製造ラインA・B・C
- 期間：7日間
- 測定間隔：1分
- 測定項目：温度、圧力、振動

## 4. 内容

- 分析目的・データ概要
- ライブラリの読み込み
- CSVデータの読み込み
- データの基本確認
- データクレンジング
- 基本統計量
- 時系列分析
- 相関分析
- 異常値候補の検出
- 分析結果のまとめ・考察

## 5. ファイル構成

- production_analysis.ipynb：データ分析Notebook
- generate_data.ipynb：サンプルデータ生成プログラム
- production_data.csv：分析用サンプルデータ

## 6. 目的

Pythonによるデータ処理・分析・可視化の技術習得を目的として制作しました。
